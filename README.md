# Paper-Mario-TOK-Maps-in-Splatoon-3

> [!CAUTION]
> **THIS MOD IS NOT ONLINE SAFE, PLEASE DO NOT USE ON SYSNAND. I AM NOT RESPONSIBLE IF YOU GET BANNED.**

This WIP will centralize all my upcoming map ports from *Paper Mario: The Origami King* into **Splatoon 3**. Instead of making multiple pages, everything will be tracked here.

---

### 🗺️ STAGES:
- **The Princess Peach** (Paintable)
- **Autumn Mountain** 
- **Mushroom Island** 
- **Picnic Road** 
- **Hotfoot Crater** (With "surface physics": Stone and Carpet)
